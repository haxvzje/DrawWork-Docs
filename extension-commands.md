# Extension Commands

Draw's available extensions!

### /extensions snipe

This command retrieves the most recently deleted message in a channel. It is particularly useful for moderators or admins who need to monitor message deletions. This command functions only for users who possess the "Message Manager" permission, ensuring that only authorized personnel can access potentially sensitive information about deleted messages.

### /extensions clear `amount`

This command deletes a specified number of messages from a channel, determined by the `amount` provided by the user. It is designed to assist in channel management and can only be executed by users with the "Message Manager" permission, ensuring that only authorized personnel can perform bulk message deletions.

### /extensions avartar `user`

This command retrieves the avatar of the specified `user`. If no user is specified, it will return your own avatar. This feature is helpful for users who want to quickly view or download a user's profile picture.

### /extensions userinfo `user`

This command provides detailed information about the specified `user`, including their account creation date, the date they joined the server, assigned roles, and current guild permissions. This is useful for administrators who need comprehensive user data for management purposes.
