# Information Commands

Provide basic information of Draw to users!

### /information info

This command provide fundamental information such as help commands to guide you, invite commands for adding contacts or users, and other informational resources for better navigation and support.

### /information invite

This command provides the official link to add Draw to your Discord server, enabling seamless integration and enhanced collaboration within your community.

### /information logs

This command will provide the Draw version and detail the changes made during the update process, helping users stay informed about the latest features and improvements.

### /information support

This command directs users to the **Draw Store**, where they can support **Draw** by purchasing a **Supporter Plan**, contributing to its continued development and enhancement.
