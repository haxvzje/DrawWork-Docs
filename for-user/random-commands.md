# Random Commands

Provides commands related to random numbers 🎲!

### /random random `min` `max`

To generate a random number within a specified range, use this command by providing the minimum (`min`) and maximum (`max`) values as arguments. The output will be a random number that falls inclusively between these two specified numbers.

### /random dick `user`

This command generates a random dick size for the specified `user`. If you omit the `user` argument, it will randomly determine your own dick size.

### /random lottery `number (from 11 to 99)`

To simulate the excitement of buying a lottery ticket. Provide a number between 11 and 99 as an argument to discover your lottery luck.
