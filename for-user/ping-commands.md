# Ping Commands

Just PING &lt;--&gt; PONG 🏓give us a signal if you're still active!

### /ping database

This command sends a signal to the `Draw's DATABASE Server` and then returns the latency of that response!

### /ping discordapi

This command sends a signal to the `Discord's API` and then returns the latency of that response!

### /ping imageapi

This command sends a signal to the `Draw's Image Server` and then returns the latency of that response!
